# Marble Arena

번호/이름을 실제 물리 구슬로 만들어 다양한 맵에서 겨루는 마블 룰렛 웹앱입니다.

## Features
- 번호 범위 자동 생성 (예: 1~30)
- 직접 참가자 입력 및 `이름*숫자` 가중치
- 4개 물리 맵: Neon Grid / Switchback / Vortex / Dropzone
- 1등 / 꼴등 / 특정 순위 당첨
- 1x / 2x / 4x 배속
- Chaos Events, Shake, Shuffle, Random Map
- 실시간 도착 순위 및 우승 결과
- 모바일 반응형

## Tech
정적 HTML/CSS/JavaScript + Matter.js 0.20.0 ESM. 별도 백엔드가 필요하지 않습니다.
